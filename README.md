# Hi! Lighter 熒光筆

Hi! Lighter 版的創作 app（建構於 Onset）：Mac、iPhone 和 iPad。

## 下載

到 [Releases](../../releases/latest) 下載 `HiLighter-3.0.0.dmg`。

DMG 有密碼保護，打開時要輸入密碼。密碼請向給你這個連結的人索取。

## 裡面有什麼

- **Hi! Lighter.app**：Mac 版（Apple 晶片 M1 以後，macOS 13 以上）。
- **iPhone-iPad/HiLighter.ipa**：iPhone 和 iPad 共用的安裝檔。
- **iPhone-iPad/AltServer.app**：把 .ipa 裝進手機用的工具（AltStore 團隊的官方 1.8 版）。
- **先看這裡 · 安裝說明.html**：安裝步驟，請先打開這個檔。

## 先知道

- Mac 版沒有經過 Apple 公證：第一次打開要到「系統設定 → 隱私權與安全性」按「強制打開」。
- iPhone / iPad 版用你自己的 Apple ID 透過 AltServer 安裝；免費 Apple ID 每 7 天要重新整理一次。
